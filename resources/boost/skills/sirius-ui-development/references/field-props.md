## field (class-backed)

| Attribute | Default |
| --- | --- |
| id | random 5 characters |
| label | null |
| name | null |
| helper | null |
| required | false |
| disabled | false |
| readonly | false |
| error-key | null |
| error-bag | default |
| errors | shared ViewErrorBag |
| layout | stacked |
| size | md |
| group | false |
| wrapper-class | empty string |
| show-required-indicator | true |
| show-errors | true |
| label-status | null |

Basic controls share one implementation. type applies to Input (text/search/number/password), resize to Textarea (none/vertical/horizontal/both), checked to choices, indeterminate to Checkbox only, and show-label/hide-label to password controls. Shared declarations do not mean every prop affects every control.
